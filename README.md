# DOCMETRY

Guía del Survival de Ederus: tier lists de armaduras, armas y anomalías, cajas y premios, encantamientos, jefes de mazmorra, mascotas, tags, economía, progresión y rangos.

Es solo para mostrar información. La página (`index.html`) se genera desde el estudio local con `build_doc.py --publico`, y aquí no se suben los datos de origen ni la configuración del servidor.
